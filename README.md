# 박재현 웹 포트폴리오

GitHub Pages 게시용 정적 사이트입니다. HTML, CSS, JavaScript만 사용하며 설치나 빌드 없이 실행할 수 있습니다.

## 페이지

- `index.html`: 사진 슬라이드, 소개, 주요 프로젝트와 기술별 구현 경험
- `work.html`: 프로젝트 목록과 보조 경험
- `ai.html`: 스킬과 컨텍스트 관리, 병렬 개발, 문서·디자인과 정보 수집 자동화
- `about.html`: 학습과 협업 방식, 기술 경험, 학력과 자격
- `bbiyong.html`, `gabolle.html`: 기능 개발, 기술 적용, 검증과 회고

로컬에서는 이 디렉터리에서 정적 HTTP 서버를 실행합니다. GitHub Pages 게시 소스는 `main` 브랜치의 `/`입니다.

## 자료와 권리

본문은 본인의 경험 기록과 제출용 포트폴리오를 바탕으로 작성했습니다. 실제 프로젝트 이미지와 GIF는 프로젝트 팀의 결과물이며, 화면과 팀 전체 기능을 개인 단독 구현으로 표현하지 않습니다. 각 페이지의 역할과 검증 범위를 따릅니다.

Pretendard 글꼴은 SIL Open Font License 1.1로 배포합니다. 원문은 `assets/fonts/LICENSE.txt`입니다.

기술 아이콘은 Devicon 공식 SVG를 사용합니다. 원본 주소와 MIT 라이선스는 `assets/icons/SOURCES.md`, `assets/icons/LICENSE.txt`에 있습니다.

첫 화면은 본인 사진 5장을 세로로 넘기는 슬라이드이며, 옆의 점으로 사진을 고를 수 있습니다. 사진은 위치 정보 등 메타데이터를 지운 WebP입니다. 스크롤하면 각 항목이 화면에 들어올 때 차례로 나타나고, 마우스 휠 스크롤은 짧게 감속합니다.

프로젝트 GIF는 화면에 들어오면 자동 재생하며 화면 밖이나 숨겨진 탭에서는 정지 포스터를 표시합니다. 별도 재생·정지 버튼은 표시하지 않습니다. 모션 감소 설정에서는 사진 슬라이드, 스크롤 연출과 감속 스크롤을 끕니다. 기술 목록은 선택과 드래그로 조작하며, 포인터나 키보드 포커스를 벗어나면 잠시 후 자동 이동을 재개합니다. JavaScript가 없으면 프로젝트 포스터와 기술별 경험 본문을 읽을 수 있습니다.

GABOLLE의 지도와 휴대폰 화면은 실제 정지 이미지입니다. 발표용 전환 영상을 앱 시연처럼 사용하지 않습니다. FLY ASIA 부스 사진은 원본의 전체 비율을 유지했습니다.

AI 페이지의 리퀴드 배경은 사용자가 제공한 디자인 참고 영상의 색보정본입니다. 원본의 움직임을 유지하고 오디오는 제외했으며, 해당 영상은 아래 MIT 코드 라이선스 대상에 포함하지 않습니다. 기존 제출용 PPT/PDF와 인증 파일은 이 저장소에 포함하지 않습니다.

© 2026 박재현. `LICENSE`(MIT)는 사이트 코드에 적용합니다. 프로젝트 팀 이미지와 개인 사진, 본문은 MIT 라이선스 대상이 아니며 권리를 별도로 양도하지 않습니다.

화면은 화이트, 오렌지와 차콜로 구성했습니다. AI 페이지의 영상은 상단 메뉴 뒤까지 채워지고 글자색은 고정됩니다. 기술 카드는 화면 양끝까지 이어지는 순환 목록이며, 모션 감소 설정에서는 자동 이동하지 않습니다.

메인 꽃잎 배경은 사용자가 제공한 wbpRv4oMbmYPoj5l.mp4 첫 프레임의 질감을 사용합니다. 원본 203프레임을 추출해 연속 시트로 비교했습니다. 배경 전체를 휘거나 미는 효과는 제거했습니다. 종이 바탕은 고정하고, SVG 마스크로 분리한 원본 질감의 꽃잎 네 부분에 15~21초 주기의 작은 회전을 각각 적용했습니다. 원본 영상 자체를 재생하는 방식은 아닙니다. 화면 밖이나 숨겨진 탭에서는 멈추며 모션 감소 설정에서는 정지합니다. 이 배경도 MIT 코드 라이선스 대상에서 제외합니다.

본문 폭은 1,200px, 소개 영역은 최대 1,360px를 기준으로 맞췄습니다. 흰색과 옅은 주황색 섹션은 번갈아 배치하고, 색 배경은 본문 폭 밖의 화면 가장자리까지 이어집니다. 모든 페이지의 왼쪽 아래에서 이전 화면과 메인으로 이동할 수 있습니다.

## 웹 미디어 최적화

Pretendard는 사이트에 쓰인 글자를 포함한 WOFF2를 우선 불러옵니다(두 굵기 합계 114,100바이트). 새 글자가 추가될 때는 전체 OTF로 폴백하므로 글자가 누락되지 않습니다. 텍스트 수정 후에는 WOFF2의 글자 범위도 갱신하는 편이 좋습니다.

AI 배경 영상은 기존 약 16.8초의 전체 흐름을 유지한 H.264 / yuv420p / 24fps 파일입니다. PC는 1280×888, 모바일은 768×532를 사용합니다. 첫 화면은 포스터를 먼저 표시하고 주요 리소스 로딩이 끝난 뒤 보이는 영상만 준비합니다. 화면 밖, 숨겨진 탭, 모션 감소와 데이터 절약 설정에서는 재생하지 않습니다. 원본 3,542,522바이트에서 PC 919,695바이트, 모바일 274,385바이트로 줄였습니다.

메인 첫 사진은 우선 로딩하고 나머지는 지연 로딩합니다. 기술 카드의 자동 이동은 화면에 보일 때만 프레임을 요청하고, 프레임마다 레이아웃 크기를 다시 읽지 않습니다.

메인 이름 영역은 반투명한 밝은 면과 고정된 차콜 글자를 사용합니다. 소개 버튼은 밝은 글자와 어두운 배경으로 대비를 확보했습니다. 포인터 조명은 마우스 움직임이 있을 때만 위치를 갱신하며 터치 기기와 모션 감소 설정에서는 실행하지 않습니다.
