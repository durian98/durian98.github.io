# 박재현 웹 포트폴리오

GitHub Pages에서 제공하는 정적 포트폴리오입니다. HTML, CSS, JavaScript로 구성하며 별도 앱 서버는 필요하지 않습니다.

## 페이지

- `index.html`: 메인, 사진, 프로젝트 요약과 기술별 경험
- `about.html`: 협업, 학습과 적용 사례, 학력과 자격
- `work.html`: 프로젝트 목록과 보조 경험
- `gabolle.html`, `bbiyong.html`: 프로젝트 상세
- `ai.html`: 데이터 분석, 모델 적용과 AI 개발 도구 활용
- `ai-motion-study.html`: 별도로 보존한 배경 시험 페이지

## 화면과 재생

흰색, 오렌지와 차콜을 사용합니다. Pretendard는 현재 본문에 필요한 WOFF2 두 굵기로 제공합니다. 상단 메뉴는 공통 위치를 사용하며 모바일 메뉴는 바깥 영역이나 Escape로 닫을 수 있습니다.

메인·AI 배경과 프로젝트 시연은 무음 반복 MP4입니다. 화면에 보일 때만 재생하고, 숨겨진 탭·모션 감소·데이터 절약 설정에서는 포스터를 유지합니다. 메인과 AI 배경은 모바일용 파일을 따로 선택합니다. AI 제목의 색상 반전은 유지하며, 위치 측정은 화면 크기와 글자 배치가 바뀔 때 수행합니다. 휠 스크롤은 브라우저 기본 동작을 사용합니다.

## 스타일과 글꼴 수정

브라우저는 `site.css` 한 개를 불러옵니다. 원본 스타일 순서는 `styles/order.json`에서 관리하며, 수정 후 `node build-styles.mjs`로 합친 파일과 HTML의 버전 값을 갱신합니다. GitHub Pages는 저장소에 포함된 결과를 그대로 제공합니다.

새 글자를 추가하면 `fonttools[woff]`가 설치된 Python에서 `python build-fonts.py`를 실행한 뒤 CSS를 다시 생성합니다. 원본 OTF는 제작용으로 보존하며 브라우저에서 자동으로 내려받지 않습니다. 현재 글꼴에 없는 문자는 시스템 글꼴로 표시됩니다.

## 자료와 권리

본문은 본인의 경험 기록과 제출용 포트폴리오를 바탕으로 작성했습니다. 프로젝트 화면과 시연은 팀이 만든 서비스의 결과물이며, 각 페이지에 담당 작업을 설명했습니다.

`LICENSE`의 MIT 라이선스는 사이트 코드에 적용합니다. 개인 사진, 프로젝트 팀의 이미지·시연, 본문과 사용자 제공 참고 영상을 편집한 배경에는 별도의 권리가 적용됩니다. Pretendard와 기술 아이콘의 출처·라이선스는 `assets/fonts/`, `assets/icons/`에 보존합니다.

검증 범위와 변경 내역은 취업 폴더의 `포트폴리오/검토/프런트엔드_20261023/`에서 관리합니다.
