# 박재현 웹 포트폴리오

GitHub Pages 게시용 정적 사이트입니다. HTML, CSS, JavaScript만 사용하며 설치나 빌드 없이 실행할 수 있습니다.

## 페이지

- `index.html`: 사진 슬라이드, 소개, 주요 프로젝트와 기술별 구현 경험
- `work.html`: 프로젝트 목록과 보조 경험
- `ai.html`: 직접 만든 스킬, 기능 개발과 검증 사례
- `about.html`: 학습과 협업 방식, 기술 경험, 학력과 자격
- `bbiyong.html`, `gabolle.html`: 기능 개발, 기술 적용, 검증과 회고

로컬에서는 이 디렉터리에서 정적 HTTP 서버를 실행합니다. GitHub Pages 게시 소스는 `main` 브랜치의 `/`입니다.

## 자료와 권리

본문은 본인의 경험 기록과 제출용 포트폴리오를 바탕으로 작성했습니다. 실제 프로젝트 이미지와 GIF는 프로젝트 팀의 결과물이며, 화면과 팀 전체 기능을 개인 단독 구현으로 표현하지 않습니다. 각 페이지의 역할과 검증 범위를 따릅니다.

Pretendard 글꼴은 SIL Open Font License 1.1로 배포합니다. 원문은 `assets/fonts/LICENSE.txt`입니다.

기술 아이콘은 Devicon 공식 SVG를 사용합니다. 원본 주소와 MIT 라이선스는 `assets/icons/SOURCES.md`, `assets/icons/LICENSE.txt`에 있습니다.

첫 화면은 본인 사진 5장을 세로로 넘기는 슬라이드이며, 옆의 점으로 사진을 고를 수 있습니다. 사진은 위치 정보 등 메타데이터를 지운 WebP입니다. 스크롤하면 각 항목이 화면에 들어올 때 차례로 나타나고, 마우스 휠 스크롤은 짧게 감속합니다.

프로젝트 GIF는 화면에 들어오면 자동 재생하며 화면 밖이나 숨겨진 탭에서는 정지 포스터를 표시합니다. 별도 재생·정지 버튼은 표시하지 않습니다. 모션 감소 설정에서는 사진 슬라이드, 스크롤 연출과 감속 스크롤을 끕니다. 기술 목록은 선택과 드래그로 조작하며, 포인터나 키보드 포커스를 벗어나면 잠시 후 자동 이동을 재개합니다. JavaScript가 없으면 프로젝트 포스터와 기술별 경험 본문을 읽을 수 있습니다.

GABOLLE의 지도와 휴대폰 화면은 실제 정지 이미지입니다. 발표용 전환 영상을 앱 시연처럼 사용하지 않습니다. FLY ASIA 부스 사진은 원본의 전체 비율을 유지했습니다.

AI 페이지의 리퀴드 배경은 사용자가 제공한 디자인 참고 영상의 색보정본입니다. 원본의 움직임을 유지하고 오디오는 제외했으며, 해당 영상은 아래 MIT 코드 라이선스 대상에 포함하지 않습니다. 기존 제출용 PPT/PDF와 인증 파일은 이 저장소에 포함하지 않습니다.
