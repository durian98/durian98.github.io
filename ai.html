AI 활용

개발과 문서 작업에서 반복하던 설명과 확인 절차를 스킬로 묶었습니다

개요

Claude Code와 Codex를 개발, 검증과 문서 정리에 씁니다. 작업할 때마다 같은 조건을 다시 설명하지 않도록 개발 순서와 글쓰기 기준을 재사용할 수 있는 작업 지침(스킬)으로 정리했습니다. 기능의 요청·응답, 공개할 정보와 실패 처리 조건은 직접 정하고, AI가 만든 변경은 확인한 뒤 반영합니다.

Claude Code · Codex
적용

작업 규칙
개발 검토 · 문장 편집 · 작업 준비 자동화

직접 만든
스킬

learning-first-development

개발할 때 검토 순서를 정해 두기

가설 검토, 작은 범위의 수정, 변경 내용 설명과 실패 상황 확인을 하나의 스킬로 묶었습니다. 작업을 맡길 때마다 이 순서를 길게 설명하는 대신, 같은 규칙을 불러와 적용합니다. 반복되는 코드와 실행은 AI에 맡기고, 변경 이유와 검증 조건을 살핍니다.

관련 작업 · GABOLLE 추천 성능 검토

추천 코드 분석과 k6 부하 시나리오 작성을 AI와 진행했습니다. 요청을 접수했다는 응답에서 측정을 끝내지 않고, 첫 코스를 조회할 때까지 확인했습니다. 대기 중인 작업과 시작하지 못한 요청도 함께 기록했고, 결과는 운영과 분리한 로컬 실험으로 남겼습니다.

korean-writing-editor

문서가 바뀌어도 같은 편집 기준 쓰기

자소서, 포트폴리오와 기술 문서에서 사실과 기여 범위를 지키며 표현을 다듬도록 만들었습니다. 글의 목적과 독자를 먼저 확인하고, 바뀐 문장을 원문과 대조하게 했습니다. Codex와 Claude Code에서 같은 원본을 쓰도록 연결해 기준을 한 곳에서 관리합니다.

사용 예시 · 웹과 제출용 포트폴리오 편집

웹의 AI 활용 내용을 PPT·PDF로 옮길 때 적용했습니다. 서로 다른 시점의 테스트 건수가 한 문장에 섞인 부분을 바로잡고, 로컬 성능 시험을 운영 성과로 쓰지 않도록 수정했습니다. 문장을 줄이는 과정에서도 수치와 담당 역할이 달라지지 않았는지 대조했습니다.

bbiyong-delivery

티켓부터 MR 초안까지 준비 절차 묶기

Jira 티켓 확인, 기능 브랜치 준비, 구현·검증과 MR 초안을 같은 순서로 진행하도록 BBIYONG 작업용 스킬을 만들었습니다. 매번 파트별 dev 브랜치와 팀 규칙을 다시 설명하는 대신, 저장소 지침과 티켓 정보를 먼저 읽게 합니다.

스킬에 구성한 작업 흐름

작업 시작을 요청하면 기존 티켓과 연결된 Story를 확인하고, 필요한 티켓 초안과 브랜치 기준을 정리하도록 했습니다. 이후 변경 내용과 검증 결과를 연결해 MR 초안까지 준비합니다. 티켓 본문, 커밋 형식과 MR 설명을 각각 다시 지시하던 절차를 하나로 모았습니다.

02

기능 개발

01

API 설계와 병렬 구현

GABOLLE의 여행 기록·피드와 동행 초대·공유 API를 만들 때는 테이블, 저장소 인터페이스, 테스트 틀을 먼저 정해 커밋했습니다. 업로드 처리와 초대·공유 구현은 서브에이전트 둘에 나눠 맡기고, 각자 다른 폴더와 테스트 DB 스키마를 쓰게 했습니다. 공개 응답에서 개인정보를 제외하는 정책은 직접 정했습니다. 생성된 코드는 변경 내용을 읽고 테스트한 뒤 팀 브랜치에 반영했습니다. 여러 사람과 AI가 동시에 작업할 때는 팀의 MCP 도구로 파일을 먼저 선점했습니다.

Claude Code 서브에이전트 · Spring Boot · PostgreSQL
02

일정 버전과 복사 규칙

일정을 편집할 때마다 기존 일정은 남겨 두고 새 버전을 저장하는 구조입니다. 고정·제외·순서 변경·되돌리기에 같은 복사 규칙을 적용하도록 정하고 AI와 구현했습니다. 안전장치를 하나씩 제거했을 때 테스트가 실패하는지 확인하며 테스트를 454개에서 519개로 늘렸습니다.

Spring Boot · JPA · 일정 버전 관리
03

화면 공통 요소

펼쳐지는 하단 시트와 사진 넘김처럼 여러 화면에서 쓰는 요소를 AI와 함께 공통 컴포넌트로 만들었습니다.

React Native · Expo
03

  • 실제 PostgreSQL을 쓰는 통합 테스트

  • 안전장치를 제거했을 때 테스트가 실패하는지 확인
